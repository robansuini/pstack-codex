# Benny for Codex

Optional issue-triage and reproduction recipes, adapted from upstream pstack. They are not installed schedules or Slack event listeners. Start from [FOR_AGENTS.md](FOR_AGENTS.md) when the user asks to configure or run Benny.

The operational prompts preserve source-thread coordinates, trusted triage markers, duplicate detection, bounded fixes, evidence capture, and draft-only PRs. Actual runs require configured Slack/tracker tools, repository access, and an app control adapter. This plugin supplies none of those credentials.

Use the Codex Automations tools only for a requested supported schedule. Slack event triggers require a separately configured event service. Never claim a trigger is active until the service confirms it.
