# pstack for Codex 0.15.36-codex.1

First Codex adaptation of pstack 0.15.36, based on `cursor/plugins` commit `2776ddd2355d6d6c8747d3964600f28daf62f049`.

## Included

- All 58 upstream top-level skills and 23 playbooks, plus the `$pstack` router.
- Explicit-only invocation, Codex delegation guidance, and parent-model defaults.
- Global installation through the `pstack-local` marketplace.
- A Node.js launcher for the PR watcher, project-scoped history guidance, and adapted optional Benny recipes.
- Original MIT attribution and a recorded upstream revision.

Maintained by Roberto Ansuini. Original pstack by Lauren Tan. This is an independent adaptation.

## Compatibility

Installation and skill discovery are verified with Codex CLI 0.164.0. The desktop app needs compatible local-plugin support. Python 3.9+ is needed for checkout scripts. Helpers have separate runtime requirements documented in the README.

CI covers Linux and macOS helpers and clean Codex installation. Windows helpers are not verified. A skill being discoverable does not prove every workflow's behavior in every project.

## Limitations

Live TLA+ checks need Java and TLC; tests without that runtime report explicit skips. Slack/tracker integrations, webhook receivers, and requested schedules need their own configuration. Installation activates none of them. Independent runs on the parent model do not provide cross-model review.

Upstream synchronization and local updates are manual in this release.
